# 旁知 Sidenote

在对话旁展开问题，把好奇整理成知识。

## 项目目标

面向 AI 对话学习与研究的辅助工具：保持主对话连续，在侧边卡片中深入探索细节，并将长对话与分支整理为可浏览、可复习的知识。

## 计划功能（尚未实现）

- 侧边问答卡片：选中文字创建分支，在卡片内连续追问。
- 上下文关联：继承创建时的相关主线背景，保留来源和按需同步入口。
- 资料阅读：总结链接或 PDF，保留出处与页码，区分事实和推断。
- 树状目录与纪要：按主题组织长对话，生成简短纪要，点击跳转原文。
- 知识归档：保存分支问答，结束学习后整理并导出知识文档。

## 当前状态

项目初始化阶段，尚未选定技术栈或实现插件。优先验证 ChatGPT 网页侧边问答体验；原生分支与独立 API 接入方式待验证。Codex 桌面端兼容性另行评估。

## 设计原则

- 区分真实问答分支和 AI 自动主题归类。
- 明确实际获得的上下文，不假设能访问完整历史、附件或内部状态。
- 主线和分支独立保存，结论由用户选择带回主线。
- 自动保存草稿，以明确的结束学习动作生成正式知识文档。
